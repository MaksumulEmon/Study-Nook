# 📌 Project Overview

StudyNook is a modern full-stack study room booking platform where students and library users can browse, search, filter, and book study rooms easily.

Users can also create and manage their own room listings while the platform prevents double bookings using smart booking conflict detection.

### 🔐 Authentication System

* Email & Password Authentication
